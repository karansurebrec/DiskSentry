WHERE THE WRITES GO · DRIVE BY DRIVE

attributing process writes to drives_
WRITING TO shows which drive each program is writing through — attributed from its open file handles (click a row to see the actual file paths). Drive-level WRITE rates are exact kernel disk counters; the per-program split across drives is estimated from handles. The gap between the two = OS kernel, cache flushes and protected processes. SESSION = bytes since DiskSentry started · LIFETIME = since the process started. Windows per-process I/O counters include file, disk and pipe traffic. Run DiskSentry as Administrator for full visibility.
